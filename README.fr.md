### ☁️ KaxCloud - hébergement de serveurs de jeu & de bots

J'ai fondé et je gère [**KaxCloud**](https://kaxcloud.com), un hébergeur français de serveurs de jeu, de bots Discord et de bases de données. Je m'occupe de tout, du matériel jusqu'au support :

- 🖥️ **Serveur dédié OVH** (Debian) configuré de A à Z : pare-feu, HTTPS exclusivement via Cloudflare, VPN WireGuard pour l'accès admin
- 🎮 **Pelican Panel + Wings** pour faire tourner les serveurs clients (FiveM, Minecraft, Garry's Mod, Project Zomboid, bots Node.js et Python...)
- 💳 **Paymenter** pour la facturation, avec un module patché pour la livraison automatique des serveurs
- 🗄️ Offres **MariaDB, PostgreSQL et Redis** managées, avec mots de passe uniques, TLS et listes d'IP autorisées
- 💾 **Sauvegardes** automatiques quotidiennes avec rotation, et dumps de bases de données cohérents
- 📊 **Page de statut**, supervision du parc et alertes sur Discord, maintenances planifiées gérées de bout en bout
- 🤖 **Bot de support** Discord avec diagnostic assisté par IA sur les tickets techniques
- 🌐 Site web en **Bun + Vite + React + TypeScript**, avec un centre d'aide

### 🚀 Autre projet : infrastructure MarseilleRP

Mise en place et administration complètes de l'infrastructure d'une communauté roleplay **FiveM** :

- 🖥️ Serveur dédié OVH (Debian 12) : pare-feu, deux instances FiveM, sauvegardes automatisées
- 🐳 Stack **Docker** (nginx-proxy + acme-companion) pour les services web
- 🗄️ **MariaDB** avec des comptes séparés en lecture et en écriture
- 🌐 Reverse proxy **Nginx** + **Cloudflare** (SSL Full strict), certificats Let's Encrypt
- 🛡️ Sécurité : **CrowdSec** + nftables, WAF Cloudflare, listes d'IP autorisées sur les interfaces sensibles
- 📊 Supervision en temps réel avec **Netdata**
- 🧰 Gestionnaire de CDN sur mesure développé en **Node.js / Express**
