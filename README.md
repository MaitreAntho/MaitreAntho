### 👨‍💻 About me

Self-taught developer. I started with **Discord bots**, then moved on to **web**, **backend**, **databases** and, more and more, **infrastructure**.

I like turning an idea into something concrete that keeps running: a script, a web app, an automation or a server set up and secured from scratch. Today I run my own hosting company, **KaxCloud**, and I contribute to the open-source panel it is built on.

---

### ☁️ KaxCloud - game server & bot hosting

I founded and run [**KaxCloud**](https://kaxcloud.com), a French host for game servers, Discord bots and databases. I handle everything, from the hardware to the support:

- 🖥️ **OVH dedicated server** (Debian) set up from scratch: firewall, Cloudflare-only HTTPS, WireGuard VPN for admin access
- 🎮 **Pelican Panel + Wings** to run customer servers (FiveM, Minecraft, Garry's Mod, Project Zomboid, Node.js and Python bots...)
- 💳 **Paymenter** for billing, with a patched module for automatic server delivery
- 🗄️ Managed **MariaDB, PostgreSQL and Redis** offers, with unique passwords, TLS and IP allow-lists
- 💾 Daily automated **backups** with rotation, and consistent database dumps
- 📊 **Status page**, fleet monitoring and alerts on Discord, scheduled maintenance handled end to end
- 🤖 Discord **support bot** with AI-assisted diagnosis on technical tickets
- 🌐 Website in **Bun + Vite + React + TypeScript**, with a help center

### 🚀 Other project: MarseilleRP infrastructure

Full setup and administration of the infrastructure of a **FiveM** roleplay community:

- 🖥️ OVH dedicated server (Debian 12): firewall, two FiveM instances, automated backups
- 🐳 **Docker** stack (nginx-proxy + acme-companion) for the web services
- 🗄️ **MariaDB** with separate read and write accounts
- 🌐 **Nginx** reverse proxy + **Cloudflare** (SSL Full strict), Let's Encrypt certificates
- 🛡️ Security: **CrowdSec** + nftables, Cloudflare WAF, IP allow-lists on sensitive interfaces
- 📊 Real-time monitoring with **Netdata**
- 🧰 Custom CDN manager built with **Node.js / Express**
