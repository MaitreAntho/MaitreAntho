### 🚀 Projet phare : infrastructure MarseilleRP

Mise en place et administration complète de l'infrastructure d'une communauté de roleplay **FiveM** :

- 🖥️ Serveur dédié OVH (Debian 12) configuré de zéro : pare-feu, deux instances FiveM, sauvegardes automatisées
- 🐳 Stack **Docker** (nginx-proxy + acme-companion) pour les services web
- 🗄️ **MariaDB** avec gestion fine des accès (comptes lecture/écriture séparés)
- 🌐 Reverse proxy **Nginx** + **Cloudflare** (SSL Full strict), gestion des certificats Let's Encrypt
- 🛡️ Sécurité : **CrowdSec** + nftables, WAF Cloudflare, IP whitelisting sur les interfaces sensibles
- 📊 Monitoring temps réel avec **Netdata**
- 🧰 CDN Manager custom développé en **Node.js / Express** pour la gestion de fichiers
